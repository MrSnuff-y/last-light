# LAST LIGHT

A neon survival game built with HTML5 Canvas and JavaScript.

## Play

Once GitHub Pages is enabled, open https://mrsnuff-y.github.io/last-light/ on an iPhone, iPad, or desktop browser.

## Controls

- Desktop: WASD or arrow keys to move; shooting is automatic.
- Touch: drag anywhere on the playfield to steer; shooting is automatic.
- Pause: press the Pause button.

## Publish via GitHub Pages

1. Upload `index.html` to the **root** of this repository. (Do not upload a ZIP alone or nest the HTML inside a folder.)
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)` and click **Save**.
5. Open https://mrsnuff-y.github.io/last-light/ when deployment is complete.

You can add the site to your iPhone Home Screen from Safari's Share menu.
